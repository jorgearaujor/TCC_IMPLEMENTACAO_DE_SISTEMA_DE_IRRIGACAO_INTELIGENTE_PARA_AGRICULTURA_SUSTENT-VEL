\chapter*{RESUMO} 
\thispagestyle{empty}



A agricultura contemporânea enfrenta o desafio de otimizar a produção alimentar ao mesmo tempo em que preserva recursos hídricos. Sistemas de irrigação eficientes são fundamentais nesse cenário, porém, muitas soluções de mercado apresentam alto custo e carecem de mecanismos de controle acessíveis. Este trabalho apresenta o desenvolvimento da arquitetura de software de um Sistema de Irrigação Inteligente de baixo custo, com o objetivo de promover a gestão sustentável do uso da água. Tendo em vista que o protótipo de hardware de Internet das Coisas (IoT), responsável pela coleta de dados do solo e ambiente, já se encontra plenamente consolidado, a presente pesquisa concentra-se no desenvolvimento da Interface de Programação de Aplicações (API) e da interface gráfica do usuário (Frontend). A API foi estruturada para receber, processar e armazenar os dados sensoriais em ambiente de nuvem, aplicando algoritmos para a predição da quantidade ideal de água necessária para as culturas, transferindo a complexidade de processamento do hardware para o backend. Paralelamente, desenvolveu-se uma interface web responsiva para o monitoramento em tempo real do histórico ambiental e o gerenciamento remoto da irrigação. O design, os fluxos de interação e a experiência de uso (UX) do sistema foram modelados e direcionados especificamente para estudantes de engenharia agrícola e agronomia, garantindo que a aplicação entregue funcionalidades alinhadas ao rigor acadêmico e prático, facilitando a tomada de decisão no manejo hídrico. A metodologia abrangeu o desenvolvimento do backend para coleta e envio de dados, a criação da interface visual, e a integração entre ambas as camadas, culminando em testes de estabilidade em ambiente controlado. Os resultados demonstram um sistema de alta confiabilidade no fluxo de informações, oferecendo uma ferramenta acessível e intuitiva. Conclui-se que o foco na estruturação robusta das camadas de software potencializou a usabilidade e a escalabilidade do projeto, consolidando uma solução tecnológica moderna e viável para o avanço da agricultura irrigada sustentável.
